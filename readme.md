# Patrones utilizados
## Composite
Este patron se utiliza aqui para almacenar de manera estructurada cada articulo de un pedido con sus respectivas indicaciones particulares. Con este patron se pueden manejar pedidos simples y complejos de igual manera, asi haciendo que no importe cuantos extras, personalizaciones o indicaciones adicionales se tengan a la hora de manejar las ordenes.

## Chain of Responsibility
Chain of responsibility es utilizado en este programa para que segun el tipo de cada articulo, este sea preparado por el miembro responsable en la cafeteria, o de lo contrario sea pasado al siguiente hasta llegar al responsable de esas preparaciones.
